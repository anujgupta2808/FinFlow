# FinFlow 🌿

> **Personal Finance Tracker & Conversational Wealth Companion**

FinFlow is an intuitive, privacy-first personal finance platform built with React and Vite. It helps individuals track cash flow, monitor subscriptions, simulate financial scenarios, and interact with a friendly, grounded AI financial coach.

---

## ✨ Features

- **Live Financial Pulse**: Real-time overview of monthly cash flow, savings rate, emergency runway, and active goals.
- **Conversational AI Companion**:
  - Natural human conversation for daily check-ins, motivation, and empathy.
  - Context-aware responses grounded in your actual ledger and budget.
  - Safe guardrails focusing on financial education, budgeting, and long-term planning (no individual speculative stock/crypto picks).
  - Optional session-based Google Gemini integration for advanced multimodal reasoning.
- **Smart Transaction Ingestion**: Parse bank alerts, statements, or manual entries with automatic merchant categorization and learned rule registry.
- **Subscription Radar**: Automatically detect and project recurring charges, cadences, and annual subscription costs.
- **Living Money Model & What-If Simulations**: Adjust income, dining, shopping, and fixed costs to see immediate impacts on runway and goal timelines.
- **Privacy First & Local-Only**: All financial records, custom rules, and model snapshots stay safely stored in your browser's local storage.
- **Clean Responsive UI**: Refined typography, distraction-free hidden scrollbars, dark/light contrast cards, and mobile-friendly drawer navigation.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `pnpm`

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/anujgupta2808/FinFlow.git
   cd FinFlow
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
